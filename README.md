# 라니스타 (Lanista)

로마 검투사 양성소(루두스)를 경영하는 자동전투 게임입니다. 검투사를 사들이고, 시설을 키우고, 계약에 맞춰 편성해 경기에 내보내며, 명예와 호감도를 쌓아 루두스를 후계자에게 넘깁니다. 폼페이 벽 낙서풍의 스틱맨 그림과 합성 효과음으로 만들었고, 규칙과 용어는 가능한 한 고증(폼페이 낙서·묘비·문헌)을 따릅니다.

- 서버 없이 브라우저에서만 돕니다. 저장은 브라우저 localStorage.
- 폰 세로 화면 기준 레이아웃이며 PC에서도 같은 비율로 보입니다.
- 8개 검투사 유형, 시설(켈라·의무실·훈련장), 시즌 행사, 루디스·독토르, 후계, 상대 파밀리아와 원한·복수, 별칭.

## 실행

```bash
npm install
npx vite              # 웹 화면 (http://localhost:5173, 주소 뒤 #42 로 시드 고정)
npm run build         # 배포용 빌드 (dist/)
npm run play          # 콘솔 대화형 플레이 (npm run play -- 42 로 시드 고정)
npm run sim -- 1000   # 봇 전략별 밸런스 시뮬레이션
npm run typecheck
```

## 구조

- `src/core/` 게임 규칙 (전투·계약·미시오·시너지·별칭·파밀리아·설정값)
- `src/web/` 웹 화면 (`main.ts` 화면, `stickman.ts` 그림 리그, `sound.ts` 효과음)
- `src/cli/` 콘솔 실행기와 시뮬레이션
- `docs/` 사전조사 → 컨셉 → 시대 배경 → 예명 풀 → 숫자 초안 → 프로토타입 변경 기록 → 플레이테스트·고증 검토
