# 숫자 초안 (1차 프로토타입)

작성일: 2026-09-09
기준: 177년 칙령 비율 (그레가리우스 1,000~2,000 / 최상급 15,000). 단위 HS(세스테르티우스).
모든 값은 `src/core/config.ts`에 있으며 시뮬레이션 결과에 따라 바뀐다.

## 검투사 능력치

- **새 게임 설정**(2026-09-17 → 09-18 개정): 시작할 때 파밀리아 색(벽화 안료 6종)만 고른다. 검투사 둘은 시장처럼 **주무기가 겹치지 않게 뽑힌다** — 물려받는 것이지 고르는 것이 아니다(유형 선택 제거). 능력치는 갓 들어온 자의 폭으로 굴리되 **계급은 베테라누스, 전적은 3~6승·0~2패**(2026-09-17: 베테라누스가 기본이므로 시작 검투사도 일반 검투사다). 능력치는 여느 신참처럼 굴린다 — 고르는 것은 개성이지 힘이 아니다. 색은 저장에 남고(`GameState.color`) 화면의 우리 편 색(베테라누스 진한 색 · 티로 옅은 색)에 쓰인다.
- **노예시장**(2026-09-17): 티로 2~3명 + 절반 확률의 베테라누스 1명. 판매대에 이미 나온 **유형**은 뽑힐 가중치 ×0.35(`market.dupWeight`, 09-18: 무조건 배제 → 확률, 주무기 → 유형 기준 — 주무기 기준이면 글라디우스 셋이 서로 억제돼 큰방패만 모으기 어려웠다). **상인 다시 부르기**(`market.reroll`, 09-18 3단계): 800 HS 에 시즌당 1번 판매대를 새로 뽑는다. 고증: 노예 상인은 떠돌았고 사람을 보내 더 불러올 수 있었다. 측정(특성몰기 봇 300판·12시즌): 같은 특성 2명(1단계) 중앙값 1시즌·못 모음 0%, 4명(2단계) 중앙값 6시즌·못 모음 7%, 6명(3단계) 12시즌 안 도달 48% — 봇은 판당 1.25번 부르고 자금·승률은 변화 없음. **첫 시즌 혜택(티로 3~4명 · 싼 매물 보장)은 없앴다** — 시작 검투사를 직접 고르므로 그 역할이 끝났다. 판매대는 되도록 **주무기가 겹치지 않게** 뽑는다(무기는 네 가지뿐이라 그보다 많아지면 겹친다).

## 부상 (2026-09-21 재정비 — 즉시 치료 없음)

- **즉시 치료를 뺐다.** 부상자는 의무실 침상에 눕혀야 낫는다: 시즌마다 1 낫고 **치료비**(`medicine.healCostByLevel` 500 → 의술 단계로 250 까지)를 시즌 정산에 낸다. 요양(+1)은 그대로.
- **침상 밖 부상자는 자연에 맡긴다** (`injury.natural`): 시즌마다 35% 낫고(−1) 25% 덧나며(+1), 나머지 그대로. 덧나 **부상 5**(`deathAt`)에 이르면 죽는다 — 전투 밖 죽음이라 **배상 없음**. 침상 수(시작 1, 최대 4)가 그래서 값어치를 갖는다.
- 봇 시뮬(가성비 200판): 침상 치료비 낸 검투사·시즌 약 7.6/판, 덧나 죽음 0.13/판(봇은 빈 침상에 눕히므로 침상 하나가 모자랄 때만). 파산율 0.5~8%(등급1만 봇이 8% — 침상 하나로 버티는 집), 승률 55~61%.
