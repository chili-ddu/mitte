## 1. 한 줄 컨셉

**당신은 검투사 양성소 주인(라니스타)이다. 검투사를 사고, 키우고, 조합해서 주최자에게 빌려주고, 살아 돌아오면 돈을 벌고 죽으면 배상금을 받는다.**

배치 조작 없음. 플레이어가 하는 일은 오직 **"누구를 사고, 누구를 내보내고, 어떤 계약을 받을지"**다.

## 3. 경제: 실제 검투사 산업 → 게임 시스템

역사적 돈 흐름은 이렇다.

1. 라니스타는 검투사를 사서(노예·전쟁포로·자원자) 먹이고 훈련시킨다. 큰 초기 투자.
2. 주최자(에디토르)가 경기를 열 때 검투사를 **빌려간다**. 검투사 1명당 대여료. 숙련자일수록 비쌈.
3. 검투사가 살아 돌아오면 그냥 대여료. **죽거나 불구가 되면 "판매"로 바뀌어 대여료의 최대 50배**를 배상.
4. 승자에게는 종려가지(팔마)와 상금 지갑이 주어진다.
5. 죽는 비율은 1세기엔 10경기당 1명꼴. 검투사는 너무 비싼 자산이라 함부로 못 죽였다.

이걸 그대로 가져온다.

### 3-1. 수입

| 수입원 | 게임 표현 |
|---|---|
| **대여료** | 매 경기 출전 검투사 1명당 지급. 계급(티로 < 베테라누스 < 프리무스 팔루스)에 따라 단가 상승. **지든 이기든 받는다** |
| **상금** | 승리 시 추가. 주최자 격에 따라 액수 차이 |
| **사망 배상금** | 내 검투사가 죽으면 대여료 × 배수(기본 20~50배). **목돈이지만 자산은 사라진다** |
| **매각** | 키운 검투사를 시장에 팔기. 베테라누스는 티로의 몇 배 |
| **명성(파마)** | 돈은 아니지만 더 격 높은 주최자가 찾아온다 → 단가·상금 상승. 승리보다 "이름 있는 검투사 보유"로 더 오른다 |
| **황제 루두스 매각** | 전적이 쌓인 검투사를 황제 직영 루두스가 사겠다고 제안. 최고가. 엔딩 조건과 연결 |

### 3-2. 지출

| 지출 | 게임 표현 |
|---|---|
| **구매** | 시장에서 검투사 구입. 티로는 싸고 능력 미지, 베테라누스는 비싸고 확정 |
| **유지비** | 매 라운드 검투사 1명당 식비·의료비. **많이 보유하면 압박** |
| **치료** | 부상자 회복에 돈과 시간(라운드 스킵) |
| **훈련** | 돈 내고 경험치 or 유형 전문화 |

### 3-3. 이 구조가 만드는 딜레마

- **죽어도 돈은 된다.** 늙은 검투사를 죽음의 계약(시네 미시오네)에 넣어 배상금을 챙길 수도 있다. 하지만 명성이 깎이고 파밀리아 사기가 떨어진다.
- **대여료는 지든 이기든 나온다.** 그래서 "약한 팀을 싸게 굴려서 유지비만 뽑는" 플레이와 "강한 팀 키워 상금 노리는" 플레이가 갈린다.
- **유지비 때문에 유닛을 쌓아둘 수 없다.** TFT의 이자 대신 이게 경제 압박 역할을 한다.
- **티로는 도박, 베테라누스는 안전.** 숨은 재능(스탯 미공개)이 티로 구매의 재미.

## 4. 코어 루프

```
[시즌 시작: 날씨·계약 제안] → [출전 선택] → [자동 전투] → [결과·정산] → [시즌 나머지: 시장·훈련·치료] → 다음 시즌
```

1년 = 봄·여름·가을·겨울 4시즌. 시즌마다 계약 0~2개. 한 판 = 3~5년(12~20시즌).
검투사 하나는 연 2~3경기가 적정. 더 굴리면 피로 누적(부상률↑).

### 4-1. 계약 제안

매 라운드 주최자 1~3명이 계약을 제시한다. 각 계약은 다음이 다르다.

- **경기 등급** (주최자 예산): 3만 이하 / 3~6만 / 6~10만 / 10~15만 / 15만 이상. 루두스 명성이 낮으면 하위 등급 계약만 온다
- 요구 인원 (예: 3명, 5명)
- **등급 비율 규정**: 예) "5명 중 베테라누스 이상 2명 필수, 그레가리우스(티로) 2명 이상 필수". 강한 유닛만 쌓는 플레이를 막는다
- 대여료 단가, 상금
- 형식: 카테르바리이(단체전) / 1:1 결투 / 시네 미시오네(패자 필사)
- **경기장**: 시골 목조(저위험 저보상, 군중 관대) / 캄파니아 석조(중간, 파벌 응원 강함) / 콜로세움(황제 주최, 연 1회, 최고 상금, 고사망률, 날씨 무효)
- **이동**: 본거지(캄파니아) 밖 계약은 시즌·비용 소모
- **날씨**(시즌·경기장별): 폭염 = 중장갑 체력 소모↑, 비 = 경량 유형 회피↓, 벨라리움 있는 경기장은 무효
- 주최자 취향: "트라키아인을 좋아함", "피를 원함", "기마전을 원함" → 명성 보너스 조건
- 상대 파밀리아 정보 일부 공개 (유형 구성만 보임)

**계약을 안 받을 수도 있다.** 대신 그 라운드 수입 0, 유지비만 나간다.

### 4-2. 출전 선택

보유 검투사 중 계약 인원만큼 고른다. **배치는 없다.** 전열/후열은 유형에 따라 자동(방패 큰 순서로 앞).

여기서 시너지가 결정된다. (5장)

### 4-3. 자동 전투

- 양쪽 검투사가 자동으로 붙는다. 룰은 단순: 가까운 적 공격, 유형별 사거리·특기 적용.
- 유형 상성이 승패의 핵심. (역사적 매치업 그대로)
- 전투 끝: 승/패/무승부(스탄테스 미시).

### 4-4. 결과·정산

- 패배한 쪽 검투사는 **미시오 판정**. 군중 호감도 + 주최자 성향 + 검투사 명성으로 생존 확률 결정.
- 살아남으면 부상(치료 필요) 또는 무사.
- 죽으면 배상금 지급, 파밀리아 사기 하락.
- 승리 검투사는 경험치 → 계급 상승.
- 대여료 + 상금 + 배상금 정산. 유지비 차감.

### 4-5. 시장·관리

- 시장: 매 라운드 새 검투사 몇 명 등장. 구매/매각.
- 치료, 훈련.
- 은퇴(루디스): 프리무스 팔루스급을 은퇴시키면 영구 보너스(교관이 되어 티로 성장 가속 등).

### 4-6. 종료 조건

- **패배**: 유지비를 못 내서 파산. 또는 검투사가 0명.
- **승리**: 황제 직영 루두스가 내 검투사를 사가거나(N명 매각), 내 검투사를 콜로세움에 초청 출전시킨다. 사설 라니스타로서 도달할 수 있는 최고점. 또는 명성 최대치 달성.
- 한 판 목표 길이: 20~30라운드, 30~40분.

## 5. 시너지: 배치 없이 조합만으로

플레이어가 조작할 수 있는 건 "누구를 내보내느냐"뿐이므로 시너지는 전부 **태그 조합**에서 나온다.

### 5-1. 유형 태그 (8종, 역사 그대로)

무르밀로 / 트라엑스 / 레티아리우스 / 세쿠토르 / 호플로마쿠스 / 프로보카토르 / 스키소르 / 에퀘스

- 각 유형은 고정 상성을 가진다. (예: 세쿠토르는 레티아리우스에게 강함)
- **상대 구성이 일부 공개되므로** 상성 맞춰 뽑는 게 핵심 판단.

#### 편성 콤보: 우리 팀 안의 장비 조합 (2026-09-09 추가)

유형 = 장비 세트이므로 유형 축은 두 얼굴을 가진다. 상대를 향한 **상성** + 팀 내 **장비 콤보**.

| 콤보 | 조건 | 효과 | 역사 근거 |
|---|---|---|---|
| 방패벽 | 큰 방패(스쿠툼) 유형 2명 이상: 무르밀로·세쿠토르·프로보카토르 | 전열 방어↑, 후열 피격↓ | 군단 방진. 스쿠타리이 파벌 |
| 사냥조 | 레티아리우스 + 세쿠토르 같은 팀 | 그물에 걸린 적을 세쿠토르가 추가타 | 역사적 숙적 쌍을 아군으로 |
| 창과 그물 | 레티아리우스 + 호플로마쿠스 | 사거리 유닛 2명: 접근 전 선제 피해 | 원거리 장비 조합 |
| 경중 조합 | 큰 방패 1명 + 작은 방패(파르물라) 1명: 무르밀로+트라엑스 등 | 상성 불리 완화(밸런스형) | 역사적 기본 매치업을 내부 균형으로 |
| 거울 | 프로보카토르 2명 | 서로 경험치 공유, 사기 안정 | 프로보카토르는 동종끼리만 대결. 훈련 파트너 |
| 절단조 | 스키소르 + 아무 큰 방패 | 적 군중제어(그물) 무효 + 방패로 보호 | 그물 절단 무기 |
| 기습 | 에퀘스 2명 | 첫 턴 동시 돌진, 상대 전열 이탈 | 에퀘스 개막전 관행 |

원칙: 콤보는 2명 조건이 대부분. 3명 이상 요구는 예명 계열에만 두어 두 축이 겹치지 않게 한다.
1차 프로토타입(유형 4종): 방패벽, 사냥조, 경중 조합 3개만.

### 5-2. 예명 계열 태그 (2026-09-09 결정: 핵심 시너지 축)

태그 축이 늘어나 정리함. **핵심 2축 = 유형(상성) + 예명 계열(시너지).** 포로 민족·자원자 동기는 시너지 조건이 아니라 예명을 뽑는 확률 테이블과 기본 능력치에만 영향(하위 풀로 흡수). 계급·파밀리아 유대·별칭은 시너지가 아닌 별도 시스템.

예명은 구매 시점에 보이므로 "이름 보고 뽑는" 판단이 생긴다.

| 계열 | 이름 예 | 주 출신 (이름 풀 확률) | 2명 | 3명 이상 |
|---|---|---|---|---|
| 자연·힘 | 오케아누스, 플람마, 티그리스, 우르수스 | 갈리아·게르만 포로 | 공격 +8% | 첫 공격 넉백. 상대 전열 흐트러짐 |
| 승리·행운 | 빅토르, 펠릭스, 인빅투스, 트리움푸스 | 로마 자원자 | 미시오 생존 +10% | 무승부 시 승리 판정 확률 |
| 신화 | 헤르메스, 아킬레스, 아약스, 헥토르 | 그리스계 노예 | 군중 호감도 +10% | 1명이 "영웅"으로 능력 대폭↑. 죽으면 나머지 사기 폭락 (리스크) |
| 별명 | 푸그낙스, 콜룸부스, 스피쿨루스, 테트라이테스 | 범죄자·빚쟁이 | 대여료 단가 −10% | 유지비 −20% |
| 지명 | 우르비쿠스, 아라킨투스, 카푸아누스 | 이탈리아 출신 | 홈 경기장 방어 +10% | 홈 경기장에서 미시오 거의 확정 |

#### 예명 중복 (고증대로 허용)

- 실제로 펠릭스·빅토르·헤르메스는 여러 루두스에 동시에 있었다. 표시는 항상 **이름 + 유형 + 소속**.
- 내 루두스 안에서 겹치면 로마식 서수: 펠릭스, 펠릭스 세쿤두스, 펠릭스 테르티우스.
- **이름 물려받기**: 별칭 붙은 스타가 죽으면 그 이름을 티로에게 줄 수 있다. 군중 호감도 일부 계승, 대신 기대치가 높아 첫 패배 시 호감도 大 하락. 실제 라니스타의 마케팅.
- 상대 팀과 동명이면 리벨루스에 "펠릭스 대 펠릭스"로 실려 군중 주목 이벤트.

|---|---|---|
| 트라키아 포로 | 자연·힘 | 공격 속도↑ |
| 갈리아·게르만 포로 | 자연·힘 | 방어↑ |
| 그리스계 노예 | 신화 | 사거리 유닛 적성 |
| 누미디아 포로 | 자연·지명 | 기마 적성 |
| 퇴역 군인 (자원자) | 승리·행운 | 규율. 사기 안정 |
| 몰락 귀족 (자원자) | 신화·승리 | 호감도↑, 사망 시 명성 타격 |
| 빚쟁이·범죄자 | 별명 | 싸다. 사기 낮음 |
| 스릴 추구자 | 승리·별명 | 사기↑, 통제 어려움 |
| 루디아리우스 (재계약) | 어느 계열이든 | 교관. 티로 성장 가속 |

### 5-3. 계급 태그와 개인 전적

그레가리우스(티로) → 베테라누스 → 프리무스 팔루스. 같은 계급끼리 묶으면 보너스 or 베테라누스가 티로를 보호.

검투사마다 **전적이 공식 기록**된다 (역사의 묘비·리벨루스 그대로).

- 출전 수, 승수, 종려가지(승리), 월계관(특별한 승리), 미시오(패배 생존) 횟수
- 대여료 단가·매각가에 직접 반영. 미시오 횟수도 가치가 있다 ("잘 지는 검투사")
- 그레가리우스는 프로그램(리벨루스)에 이름이 안 실린다. 이름이 실리는 순간부터 명성 기여

### 5-4. 파밀리아 유대

같은 조합으로 N번 함께 출전하면 "유대" 발생 → 사기 보너스. **죽으면 유대가 깨지고 남은 이들 사기 하락.** 사망이 숫자 손실 이상의 의미를 갖게 하는 장치.

## 6. 군중 호감도 (파마)

- 라운드마다 "화려하게 이기면" 상승: 상성 우위 승리, 무패 검투사, 주최자 취향 충족.
- 영향: 미시오 생존 확률, 계약 단가, 등장하는 주최자 격.
- 시네 미시오네 계약을 자주 받거나 약체를 던져 죽이면 하락.

## 7. 미시오 판정 상세 (사망 시스템의 핵심)

패배한 검투사 각각에 대해:

```
생존 확률 = 기본 60%
  + 군중 호감도 보정 (최대 +30%)
  + 검투사 개인 명성 (승수 많을수록 +)
  + 주최자 성향 (자비로움 +, 피를 원함 -)
  - 시네 미시오네 계약이면 0%
```

살아남아도 부상 확률 존재. 1세기 사망률(10경기당 1명)을 기본 밸런스 목표로.

## 8. 프로토타입 범위 (1차)

- 유형 4종만: 무르밀로, 트라엑스, 레티아리우스, 세쿠토르 (상성 2쌍이 명확)
- 예명 계열 2종: 자연·힘, 승리·행운 (출신 하위 풀은 트라키아·갈리아·로마 자원자)
- 계급 2단계: 티로, 베테라누스
- 계약 형식 1종: 카테르바리이 3:3
- 경기장 2종: 시골 목조, 캄파니아 석조. 날씨는 2차로
- 시즌제 적용 (4시즌 = 1년, 총 3년 = 12시즌)
- 경제: 대여료, 상금, 유지비, 사망 배상금, 구매/매각
- 미시오 판정 있음
- 12시즌 후 종료
- 화면: 색깔 사각형 + 텍스트. 전투는 로그 출력으로 시작

이 범위로 "돈이 굴러가고 검투사가 죽는 게 재밌는가"를 확인하는 게 1차 목표.

## 9. 아트 방향: 폼페이 낙서풍 스틱맨

- 검투사 = 스틱맨 + 장비 실루엣. 유형은 역사적으로 장비로 구분됐으므로 방패 크기·투구 볏·무기 길이만으로 8종 판독 가능.
- 근거: 폼페이 벽 낙서의 검투사 그림이 실제로 막대 몸에 장비만 그린 형태. 옆에 이름·전적이 적혀 있음.
- 톤: 모래색 배경, 벽에 긁은 듯한 거친 검정 또는 테라코타 붉은 선, UI는 돌판에 새긴 글씨.
- 실루엣 규칙 먼저 정하기: 방패 3단계(스쿠툼/파르마/파르물라), 투구 유무·볏 모양, 무기 길이.
- 사망 연출은 가볍게, 대신 묘비 텍스트(이름·전적)로 무게.
- 프로토타입은 색깔 사각형. 스틱맨은 전투 재미 확인 후 첫 아트 단계에서.
- 실물 레퍼런스: `ref/pompeii_*.jpg` (세베루스 vs 알바누스, 오케아누스 vs 아라킨투스, 몬타누스)

### 9-1. 캐릭터화: 개성은 그림이 아니라 기록에서

스틱맨의 약점(개성 없음)은 계층 분리로 해결한다. 풋볼 매니저·Super Auto Pets처럼 애착은 이름·전적·역사에서 온다.

| 계층 | 표현 | 목적 |
|---|---|---|
| 전투 화면 | 스틱맨 + 장비 실루엣 | 유형 판독만. 개성 불필요 |
| 검투사 카드 | 낙서풍 초상(투구·얼굴만). 부품 조합: 볏 3종, 상처 위치, 수염, 머리, 눈매 | 개체 식별. 투구 없는 레티아리우스는 얼굴이 보여 개성↑ (역사적으로 스타 多) |
| 이름 | 예명 풀을 출신별로 분리 (오케아누스, 플라마, 티그리스…) | 이름만으로 정체성 |
| 별칭 | 전적으로 획득. **능력치·특수 효과 포함** (9-2 참조) | 폼페이 낙서 "켈라두스, 소녀들의 한숨" 방식 |
| 묘비 | 사망 시 초상 + 이름 + 전적 | 죽음의 무게 |

**개성은 획득된다**: 그레가리우스는 순수 스틱맨 + 자동 이름. 베테라누스 승급 시 초상 생성, 리벨루스에 이름 게재, 별칭 부여. "내가 키워서 얼굴이 생긴 놈"이 애착의 핵심.

### 9-2. 별칭 = 획득 특성 (2026-09-09 결정: 능력치도 오른다)

전적 조건을 채우면 별칭이 붙고, 별칭마다 능력치 보너스 또는 특수 효과 1개. 검투사당 최대 2~3개.

| 별칭 | 획득 조건 | 효과 |
|---|---|---|
| 무패 | 5연승 | 공격 +10% |
| 불사 | 미시오 생존 3회 | 미시오 생존 확률 +20% |
| 생존자 | 동료 전멸 후 홀로 승리 | 혼자 남으면 방어 +30% |
| 군중의 연인 | 호감도 높은 경기 3승 | 출전 시 군중 호감도 보너스 |
| 도살자 | 상대 3명 사살 | 공격 +15%, 호감도 −, 상대 사기 저하 |
| 그물꾼의 악몽 | 레티아리우스 상대 3승 | 대 레티아리우스 상성 강화 |
| 노장 | 출전 10회 | 동행 티로 경험치 보너스 |
| 흉터 | 부상 3회 생존 | 최대 체력 −5%, 방어 +10% |
| 소녀들의 한숨 (실제) | 투구 없는 유형으로 3승 | 군중 호감도 보너스 大 |
| 불꽃 (실제) | 무승부 포함 10전 이상 | 공격 +10%, 루디스 거절 가능 |
| 세 유형을 다 싸우는 자 (실제) | 3개 유형으로 각 1승 | 계약마다 유형 전환 가능 |
| 살려준 자에게 죽은 자 (실제, 저주) | 미시오를 준 상대와 재대결 패배 | 그 상대에게 사망률↑. 복수 시스템 |

실제 기록 출처와 예명 풀은 03-background.md 18장.

견제 장치:
- 강해질수록 대여료 단가↑ → 주최자가 비싼 검투사를 꺼림 (등급 비율 규정과 연동)
- 사망 시 별칭도 소멸 → "키운 놈을 위험한 계약에 넣을까" 긴장
- 조건은 티로 때부터 누적되지만 **표시·발동은 베테라누스 승급 시** → 승급이 "숨은 개성이 드러나는 순간"

## 10. 아직 안 정한 것

- 이름. 가제 "라니스타".
- 한 판의 길이와 종료 조건 중 어느 쪽을 주로 할지.
- 상대 파밀리아를 손으로 짤지, 규칙으로 생성할지.
- 검투사 개인 성격(용감/겁쟁이 등) 넣을지.
- 유형 확장 후보(디마카에루스, 크루펠라리우스, 사기타리우스)를 언제 넣을지.
- 안다바타·파에그니아리우스 같은 코미디 유형을 군중 호감도용 특별 계약으로 넣을지. 넣으면 Domina 느낌의 서사가 생기지만 범위가 는다.
