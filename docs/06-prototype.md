### 1차 시뮬레이션 결과 (500판, 유지비 300, 배상 20배)

| 전략 | 파산율 | 평균 자금 | 출전당 사망 |
|---|---|---|---|
| 싼놈모으기 | 2.4% | 105,304 | 8.1% |
| 베테만 | 0.0% | 100,200 | 6.3% |
| 안전제일 | 31.4% | 20,042 | 8.9% |

문제: 시작 자금 2만이 10만으로 5배. 배상금이 수입의 40~60%로 "죽이는 게 본업". 첫 시즌 시장에 티로 2명만 나오면 팀을 못 꾸림.

### 조정

- 유지비 300 → 400
- 사망 배상 20배 → 10배
- 첫 시즌 시장 티로 3~4명 보장

### 2차 결과 (500판)

| 전략 | 파산율 | 평균 자금 | 호감도 | 출전당 사망 | 수입 구성 (대여/상금/배상) |
|---|---|---|---|---|---|
| 싼놈모으기 | 10.2% | 62,658 | 44 | 9.0% | 50k / 14k / 32k |
| 베테만 | 0.0% | 68,923 | 65 | 5.4% | 73k / 22k / 21k |
| 가성비+상성 | 9.0% | 56,440 | 44 | 9.4% | |
| 안전제일(등급1만) | 55.2% | 5,386 | 26 | 10.9% | 12k / 4k / 11k |
| 피계약만 | 86.4% | 1,789 | 20 | 17.9% | |

확인된 것:
- 사망률 5~9%는 목표(5~10%) 안. 피 계약만 받으면 18%.
- 대여료가 주 수입, 배상은 보조. 의도한 구조.
- 계약을 자주 거절하면(안전제일) 파산. 유지비 압박이 작동.

남은 밸런스 이슈:
- **베테라누스 전략이 지배적** (파산 0%, 최고 점수, 최고 호감도). 베테 구매가나 대여 시 주최자 기피를 강화해야 함. 등급 비율 규정(티로 필수)을 1차에 아직 안 넣었음 → 넣으면 완화될 것.
- "가성비+상성" 봇이 "싼놈"보다 못함 → 상성 배율(1.2~1.3)이 약하거나 상대 공개 정보(70%)가 부족. 상성이 핵심 판단이 되려면 배율을 올리거나 공개율을 높여야.
- 자금이 여전히 3배 성장. 후반 지출처(훈련, 루두스 확장)가 없어서 돈이 쌓임. 2차 프로토타입에서 훈련 시스템 추가 검토.

## 최소 웹 화면 (2026-09-09)

콘솔 텍스트로는 운영이 힘들다는 피드백 → 3단계를 앞당김. Vite + 순수 DOM + Canvas.

- `index.html`, `src/web/main.ts`, `src/web/style.css`. 룰은 `src/core` 그대로.
- 화면: 헤더(시즌·자금·유지비·호감도) / 시장 / 내 루두스(클릭으로 출전 선택) / 계약 제안 / 출전 편성(시너지·생존 확률 미리보기) / 시즌 종료.
- 전투 재생: `battle.ts`에 구조화된 `events` 추가. 색깔 사각형 + HP 바 + 피해 숫자 + 로그를 0.38초 간격으로 재생.
- 결과 모달: 생사·부상·승급·수입·호감도 변화.
- 브라우저에서 구매 → 계약 → 편성 → 전투 → 결과 → 시즌 종료까지 확인 완료. 콘솔 에러 없음.

함께 고친 것:
- 첫 시즌은 등급 1 계약만 (베테라누스 필수 계약이 첫 시즌에 나와 출전 불가했던 문제).
- 시즌 종료 알림을 alert 대신 화면 내 배너로.

알려진 표시 이슈:
- 같은 시장에 동명이 두 명 나올 수 있음 (고증상 허용이나 루두스 내 서수 표시는 미구현).
- 전투 화면 피해 숫자가 이름과 겹침.

## 그래픽 1차: 폼페이 낙서풍 스틱맨 (2026-09-09)

- 카드의 색 사각형에는 무기 아이콘(SVG) 추가.

다음 그래픽 후보: 카드 초상(투구·얼굴 부품 조합), 배경 관중석·모래 질감, 공격 궤적·먼지 이펙트, 나머지 4유형(호플로마쿠스·프로보카토르·스키소르·에퀘스).

## 그래픽 2차: 프레임 보간과 유형별 공격 동작 (2026-09-09)

사용자 피드백 순서대로 반영.

- **프레임 보간**: 자세를 바꿔치기하던 것을 키프레임 사이 보간(easeOut)으로. `clipSkeleton(clip, elapsedMs)`가 클립(키프레임 열)의 현재 자세를 돌려준다. 눕기(lying)는 회전 각도를, 무릎(kneel)은 내려앉기(sink)를 보간.
- **아기자기한 비율**: 머리 7→9, 몸 30→22, 팔 22→17. 이후 "다리를 더 높여" 요청으로 다리 17→22.
- **팬티(로인클로스)**를 엉덩이에 붙여 몸 기울기를 따라 회전.
- **무기 1.5배** + 날 두께 선 추가.
- **무기 방향은 전완 방향으로 이어짐** (자세별 특수처리 제거). 팔 각도만 바꾸면 무기 궤적이 따라온다.
- **유형별 공격 클립** (`attackClipFor`):
  - 무르밀로: `stab` — 방패 앞세우고 허리에서 수평 찌르기 (글라디우스는 찌르는 검)
  - 세쿠토르: `stab_secutor` — 찌른 뒤 한 발 더 밟고 들어감 (추격자)
  - 트라엑스: `attack` — 머리 위로 치켜들어 방패 너머로 내려찍기 (시카)
  - 레티아리우스: `net_trident` — 뒷손 그물 던지기 → 앞손 삼지창 길게 찌르기
- 사망은 `die` 클립: 피격 → 한쪽 무릎 → 쓰러짐.
- 갤러리(`gallery.html`)는 유형별 공격 자세 열 + 클립 재생 열로 재구성.

다음 그래픽 후보: 그물이 실제로 날아가 상대를 덮는 이펙트, 공격 궤적선, 피격 시 흔들림, 카드 초상, 배경.

## 그래픽 3차: 막기·그물·죽음 (2026-09-09)

- **방패 막기** `block` 자세·클립: 무르밀로·세쿠토르가 큰 방패로 첫 타격을 반감할 때 재생. 전투 이벤트에 `blocked` 플래그 추가, 로그에 "방패로 막음". 방패는 손이 앞으로 뻗을수록 정면으로 세워진다.
- **그물 발사체**: 레티아리우스 공격 시 그물이 포물선으로 날아가 상대를 덮고, 속박이 풀릴 때까지 반원 격자로 남는다.
- **죽음 재작업**: 피격 → 뒤로 휘청(stagger) → 무릎 꺾이며 앞으로 무너짐(collapse) → 눕기. 이전의 kneel 키프레임은 어색해서 제거. 눕는 자세는 팔을 늘어뜨리고 한 다리만 살짝 굽힘.
- 팬티(로인클로스) 축소. 같은 대상에 피해 숫자가 겹치면 위로 쌓임.

## 그래픽 4차: 그물 속박 액션 (2026-09-09)

- `bound` 자세: 팔이 몸에 붙고 다리가 모인 채 좌우로 버둥거림(wobble). 속박된 동안 이 자세.
- 그물 발사체: 손 높이에서 뭉친 채 출발 → 날아가며 펼쳐져(open 0→1) 회전하는 원형 격자 + 가장자리 추 4개 → 도착.
- 덮인 그물: 발밑 반원 대신 머리부터 발까지 덮는 돔(타원 격자 + 늘어진 단). 살짝 흔들림.
- 던진 동안 레티아리우스 손의 그물은 사라지고, 속박이 풀리면 돌아온다.
- 갤러리 공통 자세에 `bound` 열(그물 오버레이 포함) 추가. 막기 열은 큰 방패 유형만 표시.

## 그래픽 5차: 죽음 3종 (2026-09-09)

사용자 제안대로 죽음을 셋으로 나눔. 공격자 유형이 고른다 (`deathClipFor`).

| 클립 | 트리거 | 동작 |
|---|---|---|
| `die_forward` | 트라엑스 내려찍기 | 피격 → 한쪽 무릎(상체 세움) → 고개 떨굼 → 앞으로 엎어짐 (머리가 앞) |
| `die_back` | 무르밀로·세쿠토르 찌르기 | 피격 → 뒤로 튕겨 공중(팔다리 벌어짐, shift·lift) → 뒤로 누움 |
| `die_side` | 레티아리우스 삼지창 | 피격 → 두 무릎 풀리며 몸이 카메라 쪽으로 돌아감(turn 으로 납작) → 웅크린 채 옆으로 |

Skeleton 에 `shift`(밀림), `lift`(공중), `lieDir`(눕는 방향), `turn`(납작해짐) 추가, 보간됨.
`sink`는 이제 몸 전체를 내리지 않고 엉덩이만 낮춘다. 서 있을 때 무릎·발은 땅 아래로 못 내려감 (무릎 꿇기·웅크림에서 발이 땅을 뚫던 문제 해결).
리뷰용 페이지 `deaths.html`: 3종 × 유형별로 시간순 정지 프레임 7장.

### 무릎 관절 수정 (2026-09-10)

무릎 꿇기에서 다리가 앞으로 뻗어 보이던 원인: 뒷다리 정강이가 앞쪽(+92°)을 향해 땅을 따라 앞으로 가고 있었고, 앞다리 정강이도 거의 수평이었음.
실제 기하로 교정: 앞다리 = 허벅지 거의 수평 앞(+75), 정강이 수직(−75 → 절대 0°). 뒷다리 = 허벅지 뒤아래(−20), 정강이 땅 따라 뒤로(−70 → 절대 −90°). 엉덩이 높이(sink 10.5)는 뒷무릎이 땅에 닿는 높이.
웅크림(buckle)도 두 무릎이 앞으로 꺾이고 정강이가 뒤로 접히는 형태로.
개발 서버가 내려가 있으면 `npx vite --port 5177 --strictPort` 를 백그라운드로 띄운다.

### 죽음 3 교체: 옆으로 구겨짐 → 주저앉아 무너짐 (2026-09-10)

2D 옆모습에서 "옆으로"는 납작하게 눌러도 덩어리로만 보여 폐기. 대신 다리 풀려 털썩 주저앉음(sit) → 상체 앞으로 고꾸라짐(sit_slump) → 뒤로 넘어가 무릎 굽힌 채 누움(down_sit). 세 죽음의 구분: 무릎 하나 / 공중 / 엉덩방아. 패한 검투사가 주저앉아 항복 손가락을 들던 장면과도 맞음.

## 그래픽 구조 개편: 몸 + 장비 + 악세사리 (2026-09-10)

사용자 제안. 유형이 그림을 정하던 구조를 장비 계층으로 분리.

```
src/web/stickman.ts   몸(rig): 관절·자세·클립·보간. 유형 무관
src/web/loadout.ts    장비(Loadout): weapon / shield / helmet / extras / accessories
                      TYPE_LOADOUT: 유형 = 기본 장비 세트 (역사 고증)
```

- **동작은 무기가 정한다**: `attackClipForLoadout` (gladius=찌르기, sica=내려찍기, trident+net=그물·찌르기, spear=찌르기). `deathClipForWeapon` 도 무기 기준. 세쿠토르의 "한 발 더"만 유형 성향 예외.
- **막기는 방패가 정한다**: `hasBigShield` (scutum 만).
- **부착점**: 앞손(무기), 뒷손(방패·그물), 머리(투구), 어깨(갈레루스·흉갑), 다리(정강이받이).
- **악세사리** (별칭·전적 장식, 부착점에 겹침): laurel(월계관), scar(흉터), sash(붉은 띠), palm(종려가지), armband(완장). 별칭 시스템과 연결 예정: 무패=laurel, 흉터=scar, 승리=palm 등.
- 새 유형 추가 = `TYPE_LOADOUT` 에 세트 한 줄. 필요하면 투구·무기 도형만 추가. brimmed 투구, spear 는 미리 넣어둠 (프로보카토르·호플로마쿠스·에퀘스용).
- 갤러리에 "조합" 줄 4개: 같은 몸에 장비만 바꾼 예. 기존 호출부(`drawStickman(ctx, type, …)`)는 유형→세트 변환으로 그대로 동작.

다음: 별칭 획득 시 `accessories` 자동 부여, 검투사 카드 초상도 같은 장비 계층으로 그리기, 나머지 4유형 세트 정의.

## 오른손·왼손 구조 (2026-09-10, 사용자 제안)

**룰과 그림이 같은 장비 이름을 쓴다.**

```
src/core/equipment.ts   룰: MainHand(gladius/sica/trident/spear) · OffHand(scutum/parmula/net/none)
                        MAIN_HAND: 사거리·방어무시 / OFF_HAND: role guard(첫 피격 감소) | skill(bind)
                        TYPE_EQUIP: 유형 = {main, off}. TYPE_TRAIT: 장비로 설명 안 되는 성향(세쿠토르 pursuer)
src/web/loadout.ts      그림: {main, off, helmet, extras, accessories}. main/off 는 core 와 동일 타입
src/web/stickman.ts     attackClipForLoadout(오른손→공격 동작) · offhandClipFor(왼손→block | net_throw)
```

### 탑뷰 인트로 (2026-09-10)
- 경기장 기하에 `tilt`(0 = 평면도, 1 = 낮은 각도) 도입. 바닥 ry, 관객석 링 높이·들림, 회랑 투명도, 관중 표현(점·어깨 ↔ 앉은 스틱맨)이 tilt 로 보간.
- 준비: 탑뷰 1.2초 정지 → 1.8초 동안 기울이며(easeOut) 줌인·중심 이동 → 경기 시작.
- 성능: tilt 키프레임 7개의 경기장 캐시를 시작 시 생성, 프레임마다 가장 가까운 캐시를 그림.
- 검투사 y 매핑도 tilt 에 따라 바닥 깊이를 따른다.
- 인트로 번짐 수정: 기울기 캐시 교차 혼합(형태가 달라 번짐) → 인트로 동안은 그 순간의 tilt 로 경기장을 직접 그림. 관중은 3획 간략형(머리·몸통 선·어깨, 몸통 길이가 tilt 로 늘어나 점→앉은 사람으로 연속). 경기 중엔 tilt=1 캐시 하나만 사용.
- 관중 재작업: 옆모습 앉은 스틱맨 → **정면 앉은 모습**(머리·어깨·몸통 두 선·굽힌 두 다리·팔). 가까운 쪽(sin>0.25)은 **뒷모습**(다리 없음, 더 어두운 잉크). `drawSeated(k, back)` 하나로 통일, k=tilt 로 몸통·다리 길이가 늘어나 탑뷰 점→앉은 사람이 연속. 환호 담당은 먼 쪽만.
- 되돌림: 정면 그림 폐기, 원래 옆모습 앉은 스틱맨(한 줄 몸통) 유지 + k(tilt) 펼침만 적용. 가까운 쪽(화면 아래) 관중은 그리지 않음.
- 시네마틱(사전 줌인+슬로모션)은 **쓰러뜨림에만**. 치명타는 피격자 흔들림 최대(9, 0.32초) + "치명타!" 표시 + 함성.
- 경기 중 쓰러뜨림은 슬로모션 짧게(타격 후 0.35초, 줌아웃 0.5초). 마지막으로 쓰러지는 타격만 눕는 장면까지(0.95초, 줌아웃 1.2초).
- 관중 기준점을 발→**머리**로: 좌석 위치에 머리를 고정하고 몸·다리가 아래(경기장 쪽)로 자란다. 기울어질 때 관중이 계단과 한 몸으로 움직임 (사용자: "관중이 원래 자리가 먼저 보여 어색" → 2번 해석).
- 인트로 관중 전환(사용자 지정): 탑뷰 전원 점 → tilt 0~0.45 페이드아웃 → 0.65~1 먼 쪽만 앉은 스틱맨 페이드인. 가까운 쪽은 돌아오지 않음. 몸 자라는 중간 단계 제거.
- 관중 페이드인은 최종 좌석(tilt=1) 위치에서, tilt 0.8~1 구간에만. (기울기 진행 중 좌석이 밀려 올라가 "자리 찾아가는" 움직임이 보이던 문제)
- **승리 세레모니**: 마지막 이벤트 +1초에 승자 측 생존자가 `victory` 클립(무기 든 손 치켜들고 위아래). 관중은 3.2초 환호, 승자 이름 외침, 승자에게 줌인 후 줌아웃. 재생 종료가 세레모니만큼 연장.
- 관중 방향: 경기장 중앙을 향함(왼쪽 관객석→오른쪽, 오른쪽→왼쪽), 20%는 반대.
- 카메라를 **목표 추종** 방식으로: 매 프레임 목표(z, 중심)를 향해 지수 보간(줌인 8/s, 줌아웃 2.2/s). 결정타 줌 → 세레모니 줌이 끊기지 않고 이어짐.
- 세레모니 4종(승자마다 무작위): 무기 치켜들기 `victory` / 주최자석 경례 `salute` / 한쪽 무릎 인사 `bow` / 관객석 쪽으로 달려갔다 오는 한 바퀴 `lap`(팔 든 달리기, ±260).
- 세레모니 열광: 관중 전원 팔 든 캐시를 한 장 더 만들어, 세레모니 동안 두 판을 7Hz 로 번갈아(위로 5px 들썩) 그림. 동적 관중은 기존대로 팔 들고 들썩.
- 용어: 붉은 상자 = 주최자(에디토르)석. 경기 비용을 댄 사람, 미시오 최종 결정권.
- 주최자 반응(세레모니): 호감도 변화 ≥ +5 이면 만족 → 일어나 팔 들고 들썩, 승자에게 종려가지 포물선, "주최자가 종려가지를 내린다!". 아니면 앉은 채 "주최자는 무표정하다". 관중 열광은 결과 보기까지 유지.
- 주최자석을 트리부날로: 돌 단상+계단, 기둥 둘, 붉은 천막 차양(술), 휘장, 화환, 파스케스 든 호위(릭토르) 둘. 주변 앞 3단 좌석 비움. 세레모니 때 주최자만 반응.
- 종려가지는 줌아웃 시작 시점에 던짐(주최자석·승자 동시 가시). 주최자 던지기 자세 0.5초. 세레모니 종류는 승자마다 겹치지 않게 셔플 배정.
