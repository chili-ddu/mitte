# 09. 로마 장면 디자인 브리프 (2026-09-30)

2회차(로마)는 규칙은 다 들어갔지만 장면은 캄파니아 타운을 그대로 쓴다. 로마만의 장면이 필요하다. 이 문서는 디자인 담당(Codex)에게 넘기는 브리프다. 캡처는 `docs/img/campania-*.png` (게임 캔버스 880×400 원본).

## 지금 스타일 (지킬 것)

- **폼페이 벽 낙서풍**: 회벽 바탕, 붉은 황토 먹선(`INK` #7a3b1e 계열), 굵기 3.6의 스틱맨, 시드 기반 흔들림. 캔버스 직접 그리기(`src/web/main.ts` `drawForumScene`·`drawMarketScene`·`drawMedicScene`·`drawGraveScene`·`drawYardScene`, 1287~1500행). 이미지 파일 없음, 색과 도형만.
- **팔레트**(`style.css :root`): sand #e3d1a6 · sand2 #c8ad73 · plaster #efe1bd · paper #f4ebcf · ink #24170c · red #9b2c1c · blue #254c7f(내 루두스) · purple #5e2a5c(상대 파밀리아) · bronze #a8762b · dim #6e5d3d.
- **무대**: 가로 880×400, 땅선 y=258. 폰 세로 비율에서도 장소 하나가 한 화면에 들어온다. 마을은 가로로 이어진다: 들판 → 의무실 → 훈련소(루두스) → 포룸(공고벽) → 시장 → 성벽·성문 → 묘지.
- **UI 문법**: 공고벽 포스터 = 계약 카드, 판매대 = 시장, 침상 = 부상자, 묘비 = 사망자. 라니스타(흰 튜닉·토가, 자주색 줄 없음)가 걸어서 장소를 옮긴다.

캡처: `campania-yard.png`(훈련소·문루), `campania-forum.png`(공고벽 MVNERA·신전), `campania-market.png`(판매대 카타스타), `campania-medic.png`, `campania-grave.png`.

## 요청: 로마 세트 (같은 다섯 장소의 로마판)

방향 한 줄: **지방 도시가 로마가 되면 무엇이 달라 보이는가** — 규모·재료·색. 스타일은 그대로, 세계만 커진다.

| 장소 | 캄파니아 | 로마판 제안 (바꿔도 됨) |
|---|---|---|
| 루두스(훈련소) | 흙벽 문루 LUDUS | 루두스 마그누스 곁의 임대 루두스: 벽돌(붉은 opus latericium)+대리석 문틀, 문 위 'LVDVS' 대신 후계자 이름 |
| 포룸(공고벽) | 회벽에 포스터 4장, 작은 신전 | 포룸 로마눔: 대리석 기둥 열, 공고벽은 더 크고 포스터 6장 자리, 멀리 콜로세움 실루엣(벨라리움 돛대) |
| 시장 | 노예 상인 판매대(카타스타) | 같은 카타스타지만 차양이 크고, 뒤에 인술라(3층 공동주택) 벽 |
| 의무실 | 독립 흙집 | 회랑 딸린 석조, 갈레노스풍 약재 선반 확대 |
| 묘지 | 성문 밖 길가 묘비 | 아피아 가도: 사이프러스 나무와 큰 묘비, 길이 원근으로 멀어짐 |

- **팔레트 변주**: 바탕 회벽은 유지하되 로마는 트라베르틴 흰빛(#efe6d3 근처)과 벽돌 붉은빛(#9a4b33 근처)을 더한다. 자주색은 상대 파밀리아 색이라 배경에 쓰지 않는다.
- **인물**은 그대로(스틱맨 리그 공용). 군중은 로마에서 더 많고 토가 비율이 높다.
- **하지 말 것**: 사진·텍스처 이미지, 새 UI 버튼·메뉴, 세로 비율 깨기, 글자가 많은 간판(지렁이 글씨 규칙 유지).

## 요청한 산출물

1. 장소별 스케치 또는 참고 그림(어떤 형식이든) + 요소 목록(무엇을 어디에, 대략 크기).
2. 로마 팔레트 헥사 5~7개.
3. 가능하면 코드: `drawXScene` 에 `st.region === 'roma'` 분기(같은 함수 안에서 색·도형만 바꾸는 방식 선호). 코드는 디자인 워크트리(`/private/tmp/lanista-design-main`)에서만.

## 맥락

- 2회차는 후계자(전 회차의 루디아리우스·독토르)가 라니스타. 호감도는 후계자 명예만큼, 돈은 정착금. 도장은 직영 루두스 넷(갈리쿠스·다쿠스·마투티누스·마그누스)+스타틸리우스, 최종전은 콜로세움에서 근위대 3대3.

### 장소별 요소와 배치

좌표는 각 그리기 함수의 로컬 좌표다. 포룸·묘지는 발이 `y=0`, 훈련소·의무실은 `y=210`, 시장은 판매대 밑면이 `y=250`이다. 기존 타운 변환과 시장 축소 배율 `0.8`을 그대로 쓴다.

|---|---|---|
| 포룸 | 뒤쪽 중앙 `(286,-208)`에 폭 272·높이 64의 콜로세움 타원 실루엣, 아치 두 단과 돛대 열. 그 앞 `y=-194`부터 폭 456의 밝은 회랑 처마, 간격 69의 열주. 공고벽은 `x=0~440`으로 넓혀 같은 좌표의 여섯 공고를 받친다. 앞줄 `(18,16)`, `(302,16)`에 작은 토가 시민 둘을 더한다. | 돛대·타원 아치 → 긴 석조 회랑 → 공고 여섯 자리 → 낮은 군중 |

### 판단 근거와 유지한 경계

- 수도의 차이는 건물 높이·반복·재료에서 읽히게 했다. 공공 광장은 밝은 석재, 생활 공간은 붉은 벽돌, 성문 밖은 회색 길과 짙은 나무로 구분한다. 배경에 상대 파밀리아의 자주색 `#5e2a5c`는 쓰지 않는다.
- 콜로세움은 실제 지리·시점을 재현한 경관이 아니라, 같은 화면에서 로마를 알아보도록 압축한 원경이다. 코드에도 이 연출상의 선택을 적었다. 작은 아치와 돛대를 반복하고 대비를 낮춰 공고보다 먼저 읽히지 않게 했다.
- 공고 여섯 자리는 배경의 수용 공간이다. 계약 생성 수나 규칙을 늘리지 않는다. `FORUM.wallW=320`을 포함한 기존 상수와 `posterX0=32`, `posterY=-122`, 폭 52·높이 72·간격 68을 유지한다. 여섯째 공고 오른쪽은 `x=424`이므로 폭 440 안에 들어온다.
- `marketSlotX`, `marketTagW`, 판매대 높이, 침상 `x=16+80i`·폭 74, 묘비 배치, `cellRects`, 클릭 처리와 카메라를 유지한다. 새 배경은 인물·카드·치료 팻말보다 먼저 그린다. 의무실 끝 아치와 줄눈은 건물 폭 안에서 끝낸다.
- 로마의 포룸·시장에만 군중을 더하고 성인 일부에 기존 리그의 토가 옵션을 준다. 라니스타·검투사 그림과 `stickman.ts`는 바꾸지 않는다. 후계자의 긴 이름은 새 줄이나 판넬 대신 기존 문루 석판 폭에 맞춘다.
- 선반의 장식용 사발·붕대는 의술·약재 단계의 증가처럼 보이지 않도록 기존 약병 수 및 매달린 약재 표시와 구분한다. 큰 묘당에는 이름·전적을 쓰지 않아 플레이어 묘비와 구분한다.

### 검증

- `npm run typecheck` 통과.
- `npx vite build --configLoader runner` 통과. 기본 빌드는 심볼릭 링크인 `node_modules` 아래 `.vite-temp` 쓰기가 차단되어, 설정 로더 옵션만 바꿔 빌드했다. 의존성·설정 파일은 변경하지 않았다.
- 임시 Node 검수에서 다섯 장면의 Canvas 호출 기록을 비교했다. 인원 0·3·7 조건에서 캄파니아 호출 기록은 수정 전과 같고, 로마 분기는 실행 오류·비유한 좌표·캔버스 저장/복원 누수 없이 실행됐다. 인물 렌더러와 게임 조회는 대체 함수로 검사했으므로 실제 픽셀·애니메이션 검증을 대신하지 않는다. 공고·판매대·장면 치수 상수 및 클릭 처리 코드도 수정 전과 대조했다.
- 가로 880×400·세로 390×844 실제 브라우저 검수는 완료하지 못했다. 환경이 로컬 서버 실행을 제한했고, 브라우저 검사 도구 승인과 로컬 파일 열기도 차단됐다. 두 비율의 실제 표시와 클릭은 후속 시각 검수가 필요하다.
