# 07. 플레이테스트 메모 (2026-09-10, 시드 31, 8시즌 자동 진행)

진행 요약: 1시즌에 티로 3명 구매(10,411 HS 남음) → 8시즌 동안 4경기(2승 2패), 경기 0회 시즌이 4번. 종료 시 17,011 HS, 호감도 23, 3명 전원 베테라누스.

## 게임 흐름·밸런스에서 부족한 점

1. **팀 3명 고정 + 시즌당 1회 출전 → 계약 1건만 소화.** 검투사 3명이면 두 번째 계약은 무조건 거절(호감도 −2). 부상자 1명만 생겨도 팀을 못 꾸려 시즌이 통째로 빈다(2년차 여름: 3명 전원 부상 → 경기 0회). 6명을 확보하기 전까지는 게임이 뻣뻣함.
   - 후보: 계약별 규모를 1~3명으로 다양화(1대1 결투가 역사적 기본), 또는 부족한 자리를 "빈 자리"로 두고 출전 허용(상대도 같은 수).
2. **호감도 변동 폭이 큼.** 패배 −3, 계약 거절 −2(건당), 매 시즌 −1 → 한 시즌에 −6까지. 등급 2 문턱(25) 주변을 오르내려 등급 2 계약이 떴다 사라짐. 인원 부족으로 인한 거절까지 벌점인 건 가혹.
   - 후보: 거절 벌점을 시즌당 1회로 제한하거나, 요건 미충족(베테라누스 부족) 계약은 거절 벌점 없음.
3. **등급 2 계약이 목록 맨 앞에 오면 배정 실수 유발.** 요건 미충족 계약에도 배정이 되고 빨간 글씨만 뜬다. 편성에서 요건 미충족 계약은 잠그거나(배정 불가) 뒤로 정렬.
4. **대여료가 승패 무관 수입이라 지는 경기도 이득.** 베테라누스 3명 등급 1 출전 → 대여료 4,500, 패배해도 유지비 빼고 +3,300. 이미 알려진 문제. 후보: 패배 시 대여료 일부 감액, 또는 대여료를 등급·명성 기반으로 낮추고 상금 비중 상향.
5. **패배 시 쓰러진 3명 전원이 각각 미시오 판정 → 50%씩 부상.** 한 경기 패배로 로스터 전체가 2시즌 결장. 부상 확률(0.5)이나 기간(2시즌)을 낮추거나, 부상 1시즌으로.
6. **훈련이 화면상 존재감이 없음.** 자동 진행에서 한 번도 안 씀. 돈이 남는 후반엔 유일한 지출처인데 편성 화면의 작은 세그먼트 버튼에만 있음. 대시보드에 "훈련 가능 N명" 항목 추가 후보.
7. **승급이 3명 동시에 일어남** (같은 팀으로만 다니므로). 자연스럽지만 베테라누스 요건 계약이 갑자기 전부 열린다. 승급 조건에 상성 승·미시오 등 개인 차를 두면 로스터가 다양해짐.

## UI에서 부족한 점

8. **"시즌 진행 → (경기 없음)"이 확인 없이 넘어감.** 출전 검투사가 없거나 치료 가능한 부상자가 있으면 한 번 확인(또는 대시보드에서 치료 버튼 직접 제공).
9. **시즌 정산 화면이 텍스트 몇 줄에 빈 페이지.** 경기 결과·부상·승급·자금 변화를 초상과 함께 보여주는 비주얼 필요 (기존 후보).
10. **경기 결과 모달이 텍스트만.** 미시오 판정 장면(주최자 엄지) 연출이 없어 부상·사망이 밋밋함 (기존 후보).
11. **관리 화면 하단 '이번 시즌 계약' 패널이 대시보드와 중복.** 대시보드가 계약을 보여주므로 하단은 검투사 카드 목록만 남기거나, 카드 목록을 대시보드 아래 전체 폭으로.
12. **시장 매물 0명일 때 캔버스 중앙에 "이번 시즌 매물 없음" 텍스트.** 대시보드에 같은 안내가 있으므로 캔버스 텍스트는 제거하고 빈 카타스타만 두는 게 장면에 맞음.
13. **편성 화면에서 시장 매물 확인 불가.** 인원이 부족하다는 걸 편성에서 알게 되면 관리로 돌아가 시장까지 걸어가야 함. 편성 대시보드에 "시장 매물 N명" 안내와 바로가기 후보.
14. **경기 화면 상단 범례 "파란 방패·허리천 = 내 루두스"가 매 경기 반복.** 첫 경기 이후엔 생략 가능.

## 정상 확인된 것
- 스틱맨 기본형 통일(라니스타·NPC·상인·구경꾼), 눈·머리카락 없는 머리.
- 대시보드가 장소·상황별로 바뀜, 알림이 대시보드 맨 위 한 줄로 표시.
- 이동 시 가속 걸음과 끊김 없는 카메라, 이동 중 버튼 비활성.
- 부상자는 의무실 침상에 앉아 있고, 검투사들은 연습장 원 안에서 스파링.
- 상성·규칙 팝업과 편성 화면 규칙 패널.

## 고증 개선사항 (2026-09-10 점검) — 1~3 반영 완료, 4~5 미반영

1. ✅ **라니스타의 자주색 클라부스 제거.** 자주색 세로줄은 원로원·기사 신분 표식. 라니스타는 인파미스라 착용 불가 → 흰 토가 또는 좋은 튜닉.
2. ✅ **판결 연출의 손수건.** 흰 천(마파)은 경기 개시 신호. 살려 달라는 천 흔들기는 관중 쪽 → 주최자는 손짓·엄지, 관중이 천을 흔들도록.
3. ✅ **1대1 결투 비중 상향.** 실제 무누스는 파리아(짝 결투) 여러 쌍이 기본, 집단전(그레가팀)은 드묾 → 등급 1~2는 1대1·2대2 위주, 3대3은 대형 경기에만.
4. ✅ **검투사 확보 경로 확장.** 노예시장 외에 전쟁 포로, 형벌 죄수(담나티 아드 루둠), 자유민 계약자(아욱토라티: 가격 대신 계약금·급료·계약 기간).
5. ✅ **전통 짝 보너스.** 호감도 +2 · 미시오 +5% 로 반영. 무르밀로–트라엑스, 무르밀로–호플로마쿠스, 레티아리우스–세쿠토르 같은 정해진 조합일 때 관중 호응(호감도) 보너스. 같은 유형끼리 대결은 드물게.
6. (추상화로 유지) 분기 시즌 구조, 호감도로 여는 계약 등급.

## 플레이테스트 3차 (2026-09-11, 새 규칙 사용 봇 60판×24시즌 + 브라우저 8시즌)

봇(시설·행사·시범·독토르·지원자 사용): 파산 3%, 승률 69%(강한 상대 회피), 최종 자금 ~10,700, 호감도 77, 루디스 3.5회, 독토르 2.1명, 별칭 11.4개, 후계 0.08회(6년으로는 드묾), 최고 명예 80, 원한 재대결 12.4회, 복수 4.5회, 지원자 계약 0.6명, 로스터 평균 나이 25.6.

발견·조치:
1. **초반 과소비로 파산** — 브라우저 봇이 1시즌에 검투사 4명 + 시설(4,000)을 사고 3시즌에 파산. 시설 버튼은 구매 뒤 다음 시즌 유지비가 남을 때만 활성화하도록 고침(칸 질 강화 포함).
2. **원한 재대결이 너무 잦음**(한 판 12회) — 파밀리아 5명×3곳은 좁음 → 6명×4곳(스카이바 파밀리아 추가).
3. **별칭 과다**(11개/판) — '불꽃' 10전→15전. 나머지는 지켜봄.
4. **결과 모달 카드 크기** — 내 루두스와 상대 파밀리아 카드를 같은 크기(초상 56, 1:1 열)로.
5. **편성 화면 카드 높이 변화** — 배정된 검투사의 행동 버튼이 사라져 카드가 줄어들던 것을, 버튼을 비활성으로 남겨 높이 고정 + 하이라이트만.
6. 후계는 6년 안에 거의 안 일어남(정상). 라니스타 시작 32~40세 기준으로 20년 이상 운영해야 체감.
남은 관찰: 승률 69%는 봇이 약한 상대만 고른 결과. 실제 플레이어 체감은 직접 플레이로.

## 플레이테스트 4차 (2026-09-11, 브라우저 8시즌, 절제된 씀씀이)

## 5차 플레이테스트 (2026-09-11, 폰 390×844, 모바일 재구성 뒤)
새 게임 → 시장 구매 → 편성(3경기) → 행사 선택 → 경기·결과 → 정산 → 3시즌 진행. 콘솔 오류 없음.

잘된 것
- 관리·시장·경기·결과·정산(경기 1회) 화면이 스크롤 없이 한 화면에 들어간다. 편성은 계약 4건·검투사 3명일 때 약 220px, 정산은 경기 2회일 때 약 190px 넘침(탭 바는 고정이라 진행에는 지장 없음).
- 장소 이동: 팻말 탭·스와이프 모두 동작. 카메라가 먼저 옮겨가고 라니스타가 걸어 들어온다. 시장에서 라니스타가 왼쪽에 서고 매물 4명이 한 줄에 들어간다.
- 켈라 화면: 집 버튼으로 올라오고, 방을 누르면 그 자리에서 팝오버가 펼쳐지며 검투사를 고르면 옮겨진다(빈 칸으로도 이동). 대시보드는 증축·조리장 강화로 바뀐다.
- 의무실: 부상자가 침상에 눕고 넘치면 벽가에 앉는다. 대시보드에 치료 버튼·침상 부족 경고.
- 검투사·독토르·파밀리아 시트, 톱니바퀴 드롭 메뉴, 커스텀 드롭다운 정상.

고친 것
- 훈련소에서 라니스타(x 296)가 팔루스 훈련생(308)과 겹침 → 268 로.

남은 것 / 메모
- 시트가 열려 있으면 헤더 톱니바퀴가 덮여 눌리지 않는다(시트를 닫고 눌러야 함). 필요하면 헤더도 시트 위로 올릴 것.
- 켈라 화면은 줄이 하나일 때 아래 벽이 비어 보인다(칸이 늘면 채워짐).
- 편성 화면은 검투사가 늘면 스크롤이 생긴다. 검투사 카드를 접이식(선택된 계약에 배정 가능한 사람만 펼침)으로 줄이는 방안 검토.
- 첫 시즌부터 사망(펠릭스 1승/3전)이 나왔다. 초반 미시오 확률·잔혹 주최자 비율은 밸런스 재점검 때 같이 볼 것.
